# Pavan Dharma Adapa - Data Analyst Portfolio

![Portfolio Preview](https://img.shields.io/badge/Status-Live-success?style=for-the-badge) ![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20|%20CSS3%20|%20JS-blue?style=for-the-badge)

A high-performance, single-page personal portfolio website showcasing my data analytics expertise, projects, and professional achievements. Built with vanilla HTML5, CSS3, and JavaScript for optimal performance and hosted on GitHub Pages.

**🔗 Live Site:** [https://adapapavandharma.github.io](https://adapapavandharma.github.io)

## 🎨 Design Philosophy

**Data-Driven Minimalism** — A clean, professional aesthetic inspired by modern analytics dashboards.
* **Theme:** Midnight Blue (#0F172A) & Teal (#06B6D4)
* **Typography:** 'Inter' (Google Fonts) for high readability
* **Focus:** Performance, Accessibility, and Mobile Responsiveness

## ✨ Key Features

* **⚡ High Performance:** Zero heavy frameworks; pure Vanilla JS and CSS.
* **🎬 Interactive Elements:**
    * Typewriter effect on the Hero section ("Data Analyst | Python Expert...").
    * Scroll-triggered animations using [AOS Library](https://michalsnik.github.io/aos/).
    * Smooth scrolling navigation.
* **📱 Fully Responsive:** Adaptive layout with a mobile-friendly hamburger menu.
* **📊 Dynamic Metrics:** Prominently displayed impact stats (900K+ records analyzed, 87% accuracy).

## 🛠️ Technical Stack

* **Frontend:** HTML5, CSS3 (Flexbox & Grid), Vanilla JavaScript
* **Libraries:**
    * [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) - For scroll animations
    * [FontAwesome](https://fontawesome.com/) - For interface icons
* **Deployment:** GitHub Pages

## 🚀 How to Deploy

This project is configured for **GitHub Pages**.

1.  Clone the repository:
    ```bash
    git clone [https://github.com/adapapavandharma/adapapavandharma.github.io.git](https://github.com/adapapavandharma/adapapavandharma.github.io.git)
    ```
2.  Make your changes to `index.html` or `style.css`.
3.  Push changes to the `main` branch:
    ```bash
    git add .
    git commit -m "Update portfolio content"
    git push origin main
    ```
4.  Changes will go live automatically at `https://adapapavandharma.github.io` within 1-2 minutes.
